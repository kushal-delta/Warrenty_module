The demo

0

Start the system

2 min
Sign in as: nobody yet
  1. Double-click Start Warranty Service Demo.cmd. A small black window opens and the browser shows the login page. Leave the black window open.
  2. The top bar shows Synced once the data folder is connected (it would say Local only if app\index.html was opened directly).
  3. Login page has three doors: HO / Service, Dealer, Customer. The grey chips under the form fill in demo logins.
Say: One system, three kinds of users: Solartive's own people, dealers who sell and install, and the farmer who owns the pump.

Overview and the idea

4 min
Sign in as: admin / delta@2026
  1. Open the Dashboard — registrations, expiring warranties, open calls, overdue calls, approvals waiting, low stock. Every tile is clickable.
  2. Open Guide & System → End-to-End Flow. Show the picture One installation, three warranties, then cards A · Warranty flow and B · Service flow.
  3. Scroll to the table at the bottom: every screen has Add, Edit, Delete (guarded) and, where it makes sense, Excel import.
Say: The PPT flow is built end to end. A pump, a motor and a controller each carry their own serial number and their own warranty clock — so a service call knows exactly which unit is in warranty and which is not.
2

Masters — Add, Edit, Delete, Excel

7 min
Sign in as: admin
  1. Masters → Company Profile: Solartive name, address, GSTIN and logo flow to cards, job cards and messages. Edit and save.
  2. Product Models (15 models: 2, 3, 5, 7.5, 10 HP × pump / motor / controller). Click New, fill, save; open it with the pencil, change, save; delete it with the bin. Then try to delete a model that has serials → blocked, with the reason.
  3. Click Excel Template → the downloaded file opens with one sample row and an Instructions sheet. Click Import Excel, choose the same file → preview shows New / Exists / Error per row → Import.
  4. Spares & Rates: change a rate → a new line appears in rate history (the old rate still prices old job cards). Call Types & Valid Days: SLA days that decide the due date. Approval Rules: Level 1 Service Manager from ₹0, Level 2 HO Head from ₹10,000 — the live table on top shows where a ₹1,000, ₹6,000 and ₹15,000 job card goes.
  5. Service Centers, Engineers and Users & Rights: state rights and menu rights decide what each person sees.
Say: Nothing is hard-coded. Warranty months, SLA days, approval thresholds, rates and fault lists are all masters Solartive can maintain, in the screen or in Excel.

Serial numbers from production (Excel) → QR stickers

5 min
Sign in as: admin
  1. Warranty → Warranty Sticker Entry. Click Import Serials (Excel) and choose Import Templates\Demo_Serial_Batch_5HP.xlsx (three pump + motor + controller sets). Preview shows 9 rows ready → Import. A new batch appears.
  2. Now import Import Templates\Demo_Serial_Batch_WITH_ERRORS.xlsx: bad model, duplicate serial, empty serial and a bad date are flagged row by row; click Error report (.xlsx) to download what to fix. Nothing is imported until the file is clean.
  3. Serial / Sticker Register: filter by category or status; open a serial → Print sticker / warranty card shows the QR sticker. Print unprinted stickers prints a whole batch.
Say: Only a serial that production loaded can ever be registered. A counterfeit or wrongly typed number is rejected at the first step.

Dealer sign-up and approval

4 min
Sign in as: login page → Dealer tab, then admin
  1. On the login page click New dealer? Sign up. Fill firm name, contact, mobile, state, district, GSTIN → Sign up. Try to log in with it → awaiting approval.
  2. Sign in as admin → Warranty → Dealer Approval & Master. The new firm is Pending. Click the tick Approve & send credentials → confirm. A WhatsApp card appears with the dealer code and password. (A dealer-specific warranty period, e.g. 30 months, is set under Edit → Warranty months.)
  3. Sign out, log in as the new dealer with that code and password. The seeded Pending firm (Bharat Urja Traders) is available for the same exercise; dealer 1007 is Blocked and cannot sign in.
  4. Show Add / Edit / Delete on the dealer list, and that a dealer with installations cannot be deleted.
Say: Dealers are onboarded by the head office, not by e-mail. The dealer-specific warranty period is applied automatically at registration.

Register a warranty — dealer, farmer and head office

9 min
Sign in as: 1001 / 123 (Dealer tab), then the Customer tab, then admin
  1. Dealer: Register Warranty → New Registration. The dealer is locked to the dealer's own name. Open Guide → End-to-End Flow in another tab for a live list of unregistered sets, for example 3 HP: 2610PU30901 · 2610MO30901 · 2610CT30901 and 5 HP: 2610PU50901 · 2610MO50901 · 2610CT50901. Type the three serials; each line turns green: Authentic · Pump · model with its warranty months.
  2. Show the checks (type, read the message, fix): an unknown number → Not authenticated; an already-registered serial → Already registered on … for …; a pump of one HP with a motor of another → Check the set; a future date → rejected; a bad mobile or pincode → rejected.
  3. Fill customer mobile (a known mobile loads the farmer by itself), name, address, state, district, pincode, installation date, borewell depth, head, kWp → Activate warranty. Three warranty rows are created (pump 24 / motor 24 / controller 36 months), a WhatsApp confirmation pops up, Print warranty card opens the digital card with a QR.
  4. Farmer: sign out → Customer tab → Scan QR & register a new product (this is what the QR on the sticker opens; the same page opens directly at app/index.html#/reg?sn=<serial>). Register another set: 2610PU30902 · 2610MO30902 · 2610CT30902. No password needed; a customer account is created from the mobile number.
  5. Head office: Register Warranty → New Registration also takes a project / scheme (PM-KUSUM etc.) and back-dated installations. For many at once use Active Warranty List → Import Excel with Import Templates\Warranty_Import_Template.xlsx.
Say: Three ways in, one set of rules. The farmer needs only the sticker and a phone.
Point out: Dealer 1003 gets 30 months instead of 24 for the same pump — the warranty period follows the dealer agreement.

Replace a faulty unit in warranty

3 min
Sign in as: admin or a dealer
  1. Replacement Flow (In Warranty) → enter the old serial and a new unregistered serial of the same component → Replace in warranty.
  2. The new serial inherits the balance of the old warranty (not a fresh 24 months). The old serial is marked Replaced. Open the serial search to see the chain. The bin on the replacement row (Delete / undo replacement) reverses it.
Say: Replacing a unit never gives a customer a new full warranty by accident, and the history stays visible.

Job card (estimate) with spares and labour

Sign in as: eng.gno1

  2. Add spare and labour lines with the selectors, or click Import lines (Excel) and choose Import Templates\Demo_JobCard_Lines.xlsx (the Template button downloads the layout). Multi-level approval and stock posting

7 min
Sign in as: mgr.ind, mgr.lko, ho.head
  1. mgr.ind → Job Card Approvals (the list shows Waiting for me) → open JC/26-27/0013 (₹6,053, Level 1 only) → Approve (L1). Final approval: stock moves automatically (spares leave the engineer's van; a faulty warranty part enters damaged stock).
  2. mgr.lko → JC/26-27/0015 (₹14,868, needs two levels) → Approve Level 1 → it now waits for the HO Head. Then ho.head → Job Card Approvals → JC/26-27/0015 and JC/26-27/0014 (₹23,187 — customer-payable, already at Level 2) → Approve.
  3. JC/26-27/0016 was Rejected with a remark (rewinding alone is enough): the engineer revises and submits again, and the approval trail keeps both rounds.

Say: The approval limit is a master, not a promise in someone's head. Stock is never touched until the last approver says yes — and the final approval is refused if the spares are not actually in stock (engineer van + service-centre store), so the ledger can never go negative.

Hard questions

Are the WhatsApp messages and OTP real?

In the demo they are simulated: the phone card is what the farmer would receive and every message is stored in the log. In production one function sends to the WhatsApp Business API / SMS gateway; the message text and the trigger points stay as shown.

Where does the data live?

In the demo, in data\warranty-service-data.json next to the application. The delivered SQL Server script (database\01_create_tables.sql) is the real structure: the screens, the schema page and the data dictionary are generated from the same definition, so they cannot drift apart.

Can the warranty period or approval limits change?

Yes — warranty months per model and per dealer, SLA days per call type, approval levels and amounts are all masters (Masters menu), not code.

What if the serial list from production has more or different columns?

The importer maps columns by heading and accepts aliases; extra columns are ignored. Rows with problems are reported, never silently dropped.

Can a farmer register without a dealer?

Yes — the sticker QR opens the registration page; only a mobile number and the sticker are needed. Registrations older than 12 months must be done by the head office.

Can one customer have several installations?

Yes. Ramesh Kumar (9810101001) has two sets; each set has its own three warranties.

Is there a mobile app?

The screens are responsive and work on a phone browser; the farmer, dealer and engineer screens were laid out for that. A native app is a phase-2 conversation.

What about the existing Delta iERP modules?

This is the Warranty & Service module of Delta iERP; stock, invoicing and credit notes can be linked to the finance and inventory modules when it goes live.
