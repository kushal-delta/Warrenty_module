Open

Double-click Start Warranty Service Demo.cmd in this folder. The system opens in your browser by itself. Everything you enter is kept in data\warranty-service-data.json inside this folder, so it is still there tomorrow, it is the same in Chrome and Edge, and copying the whole folder to another PC or a pen drive carries the data with it. Leave the small black window open while you work; closing it only stops the system — the data stays in the file.

Opening app\index.html directly also works, but the browser then keeps its own private copy (the top bar says Local only).

Everything that was asked for

Flow from the PPTsSticker import → QR print → dealer sign-up and approval → registration by dealer / customer / HO → per-serial warranty → replacement → service call → visit → job card → multi-level approval → stock → close. The End-to-End Flow page inside the system shows it.
Pump · Motor · ControllerEach component is its own model, its own serial and its own warranty (pump 24, motor 24, controller 36 months). A call, a spare and a replacement are all tracked against the component serial.
Add · Edit · DeleteEvery master and transaction screen has all three. Delete is guarded — a record in use cannot be removed and the message says what uses it.
Excel import everywhere21 lists import from Excel (.xlsx / .csv) with a downloadable template, row-by-row validation, an error report and update-existing. Ready templates are in Import Templates; job-card lines import too.
Database34 tables, SQL Server script, demo data script and data dictionary in database. The Database Schema screen shows tables, ER diagram and SQL.
Roles and scopingHO (by state), service manager and engineer (by service centre), dealer (own business) and customer (own products) see only their own data.
WhatsApp / SMS / OTPSimulated for the demo: every message is shown on a phone-style card and written to the message log. A real gateway plugs in at one place.
BrandingSolartive company profile, GSTIN and logo on the login page, warranty card, job card and messages. Editable in Masters → Company Profile.
Before the demo, please note: toll-free number, e-mail, phone and website in the Company Profile are placeholders — replace them with Solartive's real details (Masters → Company Profile). All customers, dealers, serials and amounts are fictional sample data. An old .xls file must first be saved as .xlsx or .csv before import.

What is in this folder

Start Warranty Service Demo.cmdOne-click start (Windows). Uses PowerShell, already part of Windows — nothing to install.
app\The application (HTML + JavaScript, works offline).
data\Your live data file warranty-service-data.json (plus a previous copy and one snapshot per day).
database\01_create_tables.sql (SQL Server), 02_demo_data.sql (the same sample data), Data-Dictionary.xlsx (tables, columns, relationships).
Import Templates\One Excel template per importable list; each sample row imports as it is, plus bigger demo files for the live import.
Demo-Runbook.htmlThe demo script.
